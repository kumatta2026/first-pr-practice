# first-pr-practice

Practice repository for my first pull request.

## Purpose

This repository is a safe place to learn the basic pull request workflow:

1. Create a branch
2. Make a small change
3. Commit and push
4. Open a pull request
5. Review and merge

## Getting started

```bash
git clone https://github.com/kumatta2026/first-pr-practice.git
cd first-pr-practice
```

## Contributing
